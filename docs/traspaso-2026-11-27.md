## 5. Trampas

- **Quitar una página del catálogo** obliga a quitarla también de
  `instalacion/contenido-inicial.json`: el arranque rechaza una clave que el
  catálogo no tiene, y si no la siembra la vuelve a crear.
- **Migraciones de contenido:** funciones JSON, guarda que no escriba si el
  resultado no cuadra, y probar en transacción deshecha (notas §9). `JSON_SET`
  no crea un objeto intermedio que falte (`presentacion`): se rehace entero con
  `JSON_MERGE_PATCH`.
- **Si la API está levantada**, la siembra crea la página nueva antes que la
  migración: la de Patrimonio la sustituye si no tiene historial (nadie la ha
  guardado en el CMS).
- **Los ficheros del repo mezclan LF y CRLF:** una sustitución exacta con un
  script tiene que respetar el final de línea de cada fichero.
- **`sin-corporacion-escrita.test.ts`** no está en el grupo de pruebas de
  contenido que se suele pasar: pasarla siempre que se añada una página propia
  o texto neutro.
- En desarrollo sale en la consola un aviso de React por el `use()` de
  `ConBloquesCargados` en páginas con bloques que se descargan aparte (Ajuar,
  Patrimonio). Ya estaba antes; no rompe nada.
