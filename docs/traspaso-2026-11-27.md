## 5. Trampas

- **Quitar una página del catálogo** obliga a quitarla también de
  `instalacion/contenido-inicial.json`: el arranque rechaza una clave que el
  catálogo no tiene. La lista de ficheros que se tocan está en el traspaso
  del 26-11, §4; súmale `shared/rutas-publicas.json`, que se regenera con
  `npm run sitemap` en la web, y `scripts/__tests__/sitemap.test.ts`.
- **Enlaces en las migraciones:** se buscan con la comilla de **apertura**
  delante (`'"/rosario'`): así vale en un `"enlace"` y en un `href` dentro de
  un HTML guardado en JSON (`\"/rosario`), conserva el ancla y no toca
  `"/cultos/rosario"`. Repasar también `VersionContenido`, para que restaurar
  una versión vieja no traiga un enlace muerto.
- **Un título del menú que pasa a ser página** cambia de clave en
  `nombres_en_menu` (`seccion:/x` → `/x`) y sale de `secciones` en
  `entradas-del-menu.json`. En el índice de páginas del CMS va anclada, como
  Contacto, si se llama como su grupo.
- **Los heredocs de Bash en este PC** convierten `\\n` en un salto de línea
  real dentro de un script de Python: para sustituciones con `\n` literal,
  escribir el script con Write o usar Edit.
- **Prueba que corre y no acaba:** un `cat > fichero` sin heredoc se queda
  esperando la entrada y el comando no termina nunca.
