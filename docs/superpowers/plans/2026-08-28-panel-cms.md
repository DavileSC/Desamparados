# Panel del CMS y rediseño — plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Añadir un panel principal con gráficos en `/cms` y rediseñar el CMS con barra lateral oscura y lienzo claro.

**Architecture:** Un endpoint `GET /api/panel` devuelve solo agregados (nunca filas de personas), calculados en `PanelService` sobre dos funciones puras que se prueban sin base de datos. En el frontend, un tema claro anidado dentro de `AdminLayout` reviste todo el CMS sin tocar la web pública, y tres componentes SVG propios dibujan los gráficos sin añadir ninguna librería al bundle.

**Tech Stack:** Express + Prisma + MariaDB + `node:test` (backend); React 19 + MUI 9 + TanStack Query + Vitest + Testing Library (frontend).

**Spec:** `docs/superpowers/specs/2026-08-28-panel-cms-design.md`

## Global Constraints

- **Nomenclatura:** la corporación es **«Grupo Parroquial»**, nunca «Hermandad» ni «Cofradía». Los miembros sí son «hermanos». Aplica a todo texto visible.
- **Regla de oro del servicio:** `panel.service.ts` solo puede usar `count`, `groupBy` y `aggregate`. Prohibido `findMany` sobre `Hermano` y sobre `User`. Única excepción: `Evento`.
- **Cero dependencias nuevas.** Nada de librerías de gráficos: `vite.config.ts:26-31` manda todo `@mui/*` a `vendor-mui`, que descarga también el visitante de la web pública.
- **La web pública no se toca.** El tema claro va anidado dentro de `AdminLayout`, que solo envuelve las rutas `/cms`.
- **Imports del backend con extensión `.js`** (ESM), como el resto del proyecto.
- **Paleta validada, no improvisada.** Claro: `#2a78d6`, `#eb6834`, `#1baf7a`, `#eda100`. Oscuro: `#3987e5`, `#d95926`, `#199e70`, `#c98500`. Estados: ok `#1baf7a`, aviso `#eda100`, error `#e34948`.
- **Verde y ámbar no llegan a 3:1 sobre fondo claro:** todo valor con esos colores lleva **etiqueta de texto visible** junto a la marca.
- **Tras cada `git pull`,** `npx prisma generate` en el backend antes del typecheck.
- Tests backend: `npm test` (en `backend-desamparados/`). Tests frontend: `npm test` (en `desamparados-web/`).

        root: {

      },
    },

// src/components/charts/LineaTemporal.tsx
import { Box, Typography, useTheme } from '@mui/material'
import { designTokens } from '../../theme'

export interface PuntoLinea {
  x: string
  y: number
}

interface Props {
  puntos: PuntoLinea[]
  /** Qué mide la línea. Va en el aria-label y da nombre al gráfico. */
  etiqueta: string
  color?: string
  /** Segunda serie opcional, dibujada sobre la MISMA escala (ingresos y gastos). */
  comparar?: { etiqueta: string; puntos: PuntoLinea[]; color?: string }
}

const ANCHO = 600
const ALTO = 172
const MARGEN_X = 20
const SUELO = 150
const TECHO = 30

export default function LineaTemporal({ puntos, etiqueta, color, comparar }: Props) {
  const theme = useTheme()

  if (puntos.length === 0) {
    return (
      <Typography variant="body2" color="text.secondary" sx={{ py: 3 }}>
        Todavía no hay datos que enseñar aquí.
      </Typography>
    )
  }

  const series = [{ etiqueta, puntos, color: color ?? designTokens.dataviz.series[0], principal: true }]
  if (comparar && comparar.puntos.length > 0) {
    series.push({
      etiqueta: comparar.etiqueta,
      puntos: comparar.puntos,
      color: comparar.color ?? designTokens.dataviz.series[1],
      principal: false,
    })
  }

  // Escala común a todas las series. Con una escala por serie, dos líneas que
  // se cruzan no significarían nada.
  const todos = series.flatMap((s) => s.puntos.map((p) => p.y))
  const max = Math.max(...todos)
  const min = Math.min(...todos)
  // Si todos los valores son iguales el rango es 0 y la escala daría NaN.
  const rango = max - min || 1

  const trazar = (ps: PuntoLinea[]) => {
    const paso = ps.length > 1 ? (ANCHO - MARGEN_X * 2) / (ps.length - 1) : 0
    return ps.map((p, i) => ({
      cx: MARGEN_X + paso * i,
      cy: SUELO - ((p.y - min) / rango) * (SUELO - TECHO),
    }))
  }

  const descripcion = series
    .map((s) => `${s.etiqueta}: de ${s.puntos[0].y} a ${s.puntos[s.puntos.length - 1].y}`)
    .join('. ')

  return (
    <Box sx={{ width: '100%' }}>
      <svg
        viewBox={`0 0 ${ANCHO} ${ALTO}`}
        width="100%"
        role="img"
        aria-label={`${descripcion}.`}
        style={{ display: 'block', overflow: 'visible' }}
      >
        {[SUELO, 106, 62].map((y) => (
          <line key={y} x1="0" y1={y} x2={ANCHO} y2={y} stroke={theme.palette.divider} strokeWidth="1" />
        ))}

        {series.map((serie) => {
          const coordenadas = trazar(serie.puntos)
          const d = coordenadas.map((c, i) => `${i === 0 ? 'M' : 'L'}${c.cx},${c.cy}`).join(' ')
          const ultimo = coordenadas[coordenadas.length - 1]
          const ultimoValor = serie.puntos[serie.puntos.length - 1]
          return (
            <g key={serie.etiqueta}>
              {/* El área solo bajo la serie principal: dos rellenos superpuestos
                  ensucian y ninguna de las dos se lee bien. */}
              {serie.principal && (
                <path
                  d={`${d} L${ultimo.cx},${SUELO} L${coordenadas[0].cx},${SUELO} Z`}
                  fill={serie.color}
                  opacity="0.13"
                />
              )}
              <path
                data-testid={serie.principal ? 'linea' : 'linea-comparada'}
                d={d}
                fill="none"
                stroke={serie.color}
                strokeWidth="2"
                strokeLinecap="round"
                strokeLinejoin="round"
              />
              <circle cx={ultimo.cx} cy={ultimo.cy} r="5" fill={serie.color} stroke={theme.palette.background.paper} strokeWidth="2">
                <title>{`${serie.etiqueta} · ${ultimoValor.x}: ${ultimoValor.y}`}</title>
              </circle>
            </g>
          )
        })}
      </svg>

      {/* Leyenda obligatoria a partir de dos series: el color por sí solo no
          identifica nada para quien no lo distingue. */}
      {series.length > 1 && (
        <Box sx={{ display: 'flex', gap: 2, mt: 1 }}>
          {series.map((serie) => (
            <Box key={serie.etiqueta} sx={{ display: 'inline-flex', alignItems: 'center', gap: 0.75 }}>
              <Box sx={{ width: 9, height: 9, borderRadius: '2px', backgroundColor: serie.color }} />
              <Typography variant="caption" color="text.secondary">{serie.etiqueta}</Typography>

        </Box>

// src/domain/panel-censo.ts

export interface MovimientoMensual {
  /** 'YYYY-MM' */
  mes: string;
  total: number;
}

export interface PuntoCenso {
  mes: string;
  activos: number;
}

/** Etiqueta 'YYYY-MM' de una fecha, en UTC para no depender de la zona del servidor. */
export function claveMes(fecha: Date): string {
  const mes = String(fecha.getUTCMonth() + 1).padStart(2, '0');
  return `${fecha.getUTCFullYear()}-${mes}`;
}

/** Los `cuantos` últimos meses hasta `hasta`, del más antiguo al más reciente. */
export function ultimosMeses(hasta: Date, cuantos: number): string[] {
  const meses: string[] = [];
  for (let i = cuantos - 1; i >= 0; i--) {
    const fecha = new Date(Date.UTC(hasta.getUTCFullYear(), hasta.getUTCMonth() - i, 1));
    meses.push(claveMes(fecha));
  }
  return meses;
}

/**
 * Reconstruye cuántos hermanos activos había al cierre de cada mes.
 *
 * No se puede consultar directamente: la base de datos solo sabe quién está
 * activo HOY, con su fecha de alta y su fecha de baja. Así que se parte del
 * total actual y se camina hacia atrás:
 *
 *     activos(mes anterior) = activos(mes) - altas(mes) + bajas(mes)
 */
export function serieCensoMensual(
  activosHoy: number,
  altas: MovimientoMensual[],
  bajas: MovimientoMensual[],
  meses: string[],
): PuntoCenso[] {
  const porMes = (lista: MovimientoMensual[]) =>
    new Map(lista.map((m) => [m.mes, m.total]));
  const altasPorMes = porMes(altas);
  const bajasPorMes = porMes(bajas);

  const serie: PuntoCenso[] = new Array(meses.length);
  let acumulado = activosHoy;

  for (let i = meses.length - 1; i >= 0; i--) {
    serie[i] = { mes: meses[i], activos: Math.max(0, acumulado) };
    acumulado = acumulado - (altasPorMes.get(meses[i]) ?? 0) + (bajasPorMes.get(meses[i]) ?? 0);
  }

  return serie;
}

export interface Recuento {

/** Minúsculas, sin espacios sobrantes ni dobles: dos formas de escribir lo mismo caen juntas. */
function normalizar(valor: string): string {

function capitalizar(valor: string): string {
  return valor.charAt(0).toUpperCase() + valor.slice(1);

/**
 * Cuenta valores de un campo de texto libre, uniendo las variantes de escritura.
 * Devuelve los `top` mayores y mete el resto en «Otros».
 */
export function agruparPorTextoLibre(
  valores: (string | null | undefined)[],
  top = 5,
): Recuento[] {
  const cuenta = new Map<string, number>();

  for (const valor of valores) {
    if (typeof valor !== 'string') continue;
    const clave = normalizar(valor);
    if (!clave) continue;
    cuenta.set(clave, (cuenta.get(clave) ?? 0) + 1);
  }

  const ordenadas = [...cuenta.entries()]
    .map(([clave, total]) => ({ etiqueta: capitalizar(clave), total }))
    .sort((a, b) => b.total - a.total || a.etiqueta.localeCompare(b.etiqueta, 'es'));

  if (ordenadas.length <= top) return ordenadas;

  const cabeza = ordenadas.slice(0, top);
  const cola = ordenadas.slice(top).reduce((suma, fila) => suma + fila.total, 0);
  return [...cabeza, { etiqueta: 'Otros', total: cola }];
}

import { EstadoPago, TipoTransaccion, type TipoEvento } from '@prisma/client';
import db from '../config/db.js';
import { serieCensoMensual, ultimosMeses, claveMes, type MovimientoMensual } from '../domain/panel-censo.js';
import { agruparPorTextoLibre, type Recuento } from '../domain/panel-agrupar.js';

/**
 * REGLA DE ORO DE ESTE FICHERO
 *
 * Solo `count`, `groupBy` y `aggregate`. Prohibido `findMany` sobre Hermano y
 * sobre User: el panel es informativo y no puede enseñar datos de personas.
 * Única excepción: Evento, que son actos públicos.
 */

export interface PanelResponse {
  generadoEn: string;
  censo: {
    activos: number;
    altas12m: number;
    bajas12m: number;
    sinNumeroHermano: number;
    serieMensual: { mes: string; activos: number }[];
    porEdad: { tramo: string; total: number }[];
  };
  dinero: {
    porEstado: { estado: EstadoPago; total: number; importe: number }[];
    ejercicio: { anio: number; ingresos: number; gastos: number; saldo: number };
    serieMensual: { mes: string; ingresos: number; gastos: number }[];
    porCategoria: { categoria: string; tipo: TipoTransaccion; total: number }[];
  };
  procesion: {
    anio: number;
    papeletas: number;
    porAnio: { anio: number; total: number }[];
    porPuesto: Recuento[];
    porTalla: Recuento[];
    porAlturaHombro: { tramo: string; total: number }[];
  };
  actividad: {
    proximosEventos: { id: number; title: string; startDate: string; type: TipoEvento }[];
    noticias: { publicadas: number; borradores: number };
    publicaciones: { total: number; ultima: string | null };
    reparto: { turnosProximos: number; citasReservadas: number; capacidadEstimada: number };
  };
}

/** Tramos de altura de hombro, en cm, para prever cuántos varales de cada medida hacen falta. */
const TRAMOS_ALTURA = [
  { tramo: 'Menos de 160', min: 0, max: 159 },
  { tramo: '160-169', min: 160, max: 169 },
  { tramo: '170-179', min: 170, max: 179 },
  { tramo: '180 o más', min: 180, max: 300 },
];

const TRAMOS_EDAD = [
  { tramo: '0-17', min: 0, max: 17 },
  { tramo: '18-30', min: 18, max: 30 },
  { tramo: '31-45', min: 31, max: 45 },
  { tramo: '46-60', min: 46, max: 60 },
  { tramo: '61+', min: 61, max: 200 },
];

function edad(nacimiento: Date, hoy: Date): number {
  let anios = hoy.getUTCFullYear() - nacimiento.getUTCFullYear();
  const mes = hoy.getUTCMonth() - nacimiento.getUTCMonth();
  if (mes < 0 || (mes === 0 && hoy.getUTCDate() < nacimiento.getUTCDate())) anios--;
  return anios;
}

/** Agrupa fechas por 'YYYY-MM' contando cuántas caen en cada mes. */
function contarPorMes(fechas: (Date | null)[]): MovimientoMensual[] {
  const cuenta = new Map<string, number>();
  for (const fecha of fechas) {
    if (!fecha) continue;
    const mes = claveMes(fecha);
    cuenta.set(mes, (cuenta.get(mes) ?? 0) + 1);
  }
  return [...cuenta.entries()].map(([mes, total]) => ({ mes, total }));
}

export class PanelService {
  static async getPanel(): Promise<PanelResponse> {
    const hoy = new Date();
    const anio = hoy.getUTCFullYear();
    const meses = ultimosMeses(hoy, 12);
    const haceUnAnio = new Date(Date.UTC(anio - 1, hoy.getUTCMonth(), hoy.getUTCDate()));
    const inicioEjercicio = new Date(Date.UTC(anio, 0, 1));

    const [
      activos,
      altas12m,
      bajas12m,
      sinNumeroHermano,
      fechasAlta,
      fechasBaja,
      nacimientos,
      recibosPorEstado,
      transaccionesPorTipo,
      transaccionesPorCategoria,
      transaccionesPorMes,
      papeletasPorAnio,
      puestos,
      tallas,
      alturas,
      proximosEventos,
      noticiasPublicadas,
      noticiasBorradores,
      publicaciones,
      ultimaPublicacion,
      turnosProximos,
      citasReservadas,
      capacidad,
    ] = await Promise.all([
      db.hermano.count({ where: { activo: true } }),
      db.hermano.count({ where: { fechaAlta: { gte: haceUnAnio } } }),
      db.hermano.count({ where: { fechaBaja: { gte: haceUnAnio } } }),
      db.hermano.count({ where: { activo: true, numeroHermano: null } }),
      db.hermano.groupBy({ by: ['fechaAlta'], _count: { _all: true }, where: { fechaAlta: { gte: haceUnAnio } } }),
      db.hermano.groupBy({ by: ['fechaBaja'], _count: { _all: true }, where: { fechaBaja: { gte: haceUnAnio } } }),
      db.hermano.groupBy({ by: ['fechaNacimiento'], _count: { _all: true }, where: { activo: true } }),
      db.recibo.groupBy({ by: ['estado'], _count: { _all: true }, _sum: { importe: true } }),
      db.transaccion.groupBy({ by: ['tipo'], _sum: { importe: true }, where: { fecha: { gte: inicioEjercicio } } }),
      db.transaccion.groupBy({ by: ['categoriaId', 'tipo'], _count: { _all: true }, where: { fecha: { gte: inicioEjercicio } } }),
      db.transaccion.groupBy({ by: ['tipo', 'fecha'], _sum: { importe: true }, where: { fecha: { gte: haceUnAnio } } }),
      db.papeletaSitio.groupBy({ by: ['year'], _count: { _all: true } }),
      db.papeletaSitio.groupBy({ by: ['puesto'], _count: { _all: true }, where: { year: anio } }),
      db.hermano.groupBy({ by: ['tunica'], _count: { _all: true }, where: { activo: true } }),
      db.hermano.groupBy({ by: ['alturaHombro'], _count: { _all: true }, where: { activo: true, alturaHombro: { not: null } } }),
      db.evento.findMany({
        where: { startDate: { gte: hoy } },
        orderBy: { startDate: 'asc' },
        take: 5,
        select: { id: true, title: true, startDate: true, type: true },
      }),
      db.noticia.count({ where: { visible: true } }),
      db.noticia.count({ where: { visible: false } }),
      db.publicacion.count(),
      db.publicacion.aggregate({ _max: { fecha: true } }),
      db.turno.count({ where: { fecha: { gte: hoy }, activo: true } }),
      db.cita.count({ where: { estado: 'RESERVADA' } }),
      db.turno.aggregate({ _sum: { capacidadEstimada: true }, where: { fecha: { gte: hoy }, activo: true } }),
    ]);

    // Las categorías se resuelven aparte: groupBy devuelve el id, no el nombre.
    const categorias = await db.categoriaTransaccion.findMany({ select: { id: true, nombre: true } });
    const nombreCategoria = new Map(categorias.map((c) => [c.id, c.nombre]));

    const ingresos = Number(
      transaccionesPorTipo.find((t) => t.tipo === TipoTransaccion.INGRESO)?._sum.importe ?? 0,
    );
    const gastos = Number(
      transaccionesPorTipo.find((t) => t.tipo === TipoTransaccion.GASTO)?._sum.importe ?? 0,
    );

    const porEdad = TRAMOS_EDAD.map(({ tramo, min, max }) => ({
      tramo,
      total: nacimientos
        .filter((n) => {
          const e = edad(n.fechaNacimiento, hoy);
          return e >= min && e <= max;
        })
        .reduce((suma, n) => suma + n._count._all, 0),
    }));

    // Ingresos y gastos mes a mes. groupBy agrupa por fecha exacta, así que el
    // reparto por mes se hace aquí, sobre las sumas ya calculadas.
    const serieDinero = meses.map((mes) => {
      const delMes = transaccionesPorMes.filter((t) => claveMes(t.fecha) === mes);
      const suma = (tipo: TipoTransaccion) =>
        delMes.filter((t) => t.tipo === tipo).reduce((s, t) => s + Number(t._sum.importe ?? 0), 0);
      return { mes, ingresos: suma(TipoTransaccion.INGRESO), gastos: suma(TipoTransaccion.GASTO) };
    });

    // Cuántos hermanos hay de cada altura de hombro: es lo que decide cuántos
    // varales de cada medida hay que preparar.
    const porAlturaHombro = TRAMOS_ALTURA.map(({ tramo, min, max }) => ({
      tramo,
      total: alturas
        .filter((a) => a.alturaHombro !== null && a.alturaHombro >= min && a.alturaHombro <= max)
        .reduce((suma, a) => suma + a._count._all, 0),
    }));

    // groupBy da una fila por valor distinto; agruparPorTextoLibre espera la
    // lista repetida, así que se expande por su recuento.
    const expandir = <T extends { _count: { _all: number } }>(filas: T[], valor: (f: T) => string | null) =>
      filas.flatMap((f) => new Array<string | null>(f._count._all).fill(valor(f)));

    return {
      generadoEn: hoy.toISOString(),
      censo: {
        activos,
        altas12m,
        bajas12m,
        sinNumeroHermano,
        serieMensual: serieCensoMensual(
          activos,
          contarPorMes(fechasAlta.flatMap((f) => new Array(f._count._all).fill(f.fechaAlta))),
          contarPorMes(fechasBaja.flatMap((f) => new Array(f._count._all).fill(f.fechaBaja))),
          meses,
        ),
        porEdad,
      },
      dinero: {
        porEstado: recibosPorEstado.map((r) => ({
          estado: r.estado,
          total: r._count._all,
          importe: Number(r._sum.importe ?? 0),
        })),
        ejercicio: { anio, ingresos, gastos, saldo: ingresos - gastos },
        serieMensual: serieDinero,
        porCategoria: transaccionesPorCategoria.map((t) => ({
          categoria: nombreCategoria.get(t.categoriaId) ?? 'Sin categoría',
          tipo: t.tipo,
          total: t._count._all,
        })),
      },
      procesion: {
        anio,
        papeletas: puestos.reduce((suma, p) => suma + p._count._all, 0),
        porAnio: papeletasPorAnio
          .map((p) => ({ anio: p.year, total: p._count._all }))
          .sort((a, b) => a.anio - b.anio)
          .slice(-5),
        porPuesto: agruparPorTextoLibre(expandir(puestos, (p) => p.puesto)),
        porTalla: agruparPorTextoLibre(expandir(tallas, (t) => t.tunica)),
        porAlturaHombro,
      },
      actividad: {
        proximosEventos: proximosEventos.map((e) => ({
          id: e.id,
          title: e.title,
          startDate: e.startDate.toISOString(),
          type: e.type,
        })),
        noticias: { publicadas: noticiasPublicadas, borradores: noticiasBorradores },
        publicaciones: {
          total: publicaciones,
          ultima: ultimaPublicacion._max.fecha?.toISOString() ?? null,
        },
        reparto: {
          turnosProximos,
          citasReservadas,
          capacidadEstimada: capacidad._sum.capacidadEstimada ?? 0,
        },
      },
    };
  }
}

/** Los estados de recibo que interesan en el panel, con su severidad. */
const ESTADOS = [
  { clave: 'PAGADO', etiqueta: 'Cobrados', estado: 'ok' as const },

function Bloque({ titulo, children }: { titulo: string; children: React.ReactNode }) {
  return (
    <Paper sx={{ p: { xs: 2, md: 3 }, display: 'flex', flexDirection: 'column', gap: 2 }}>

      {children}

            etiqueta="Hermanos activos mes a mes"
            puntos={data.censo.serieMensual.map((p) => ({ x: p.mes, y: p.activos }))}

## Notas para quien ejecute

- **No añadas dependencias.** Si un gráfico se resiste, es preferible simplificarlo a instalar una librería: el motivo está en las restricciones globales.
- **Los tests que necesitan MariaDB se omiten con motivo**, nunca se marcan como pasados. Si ves «omitido», arranca la base de datos y vuelve a ejecutarlos antes de dar nada por bueno.
- **`npx prisma generate` después de cada `git pull`**, o el typecheck fallará con errores raros de tipos de Prisma.
- **Textos visibles:** «Grupo Parroquial», nunca «Hermandad» ni «Cofradía».
- **El menú móvil no se prueba solo.** `src/test/setup.ts` no define `window.matchMedia`, así que en jsdom `useMediaQuery` devuelve siempre `false` y los tests de `AdminLayout` ven la versión de escritorio. Es correcto —así se comprueban los enlaces—, pero el `Drawer` hay que mirarlo a mano: es el paso 6 de la tarea 13.
